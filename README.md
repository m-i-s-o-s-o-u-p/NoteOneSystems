# 🏢 Studio 0% Holdings

費用0円（完全無料）で24時間365日稼働する、AI社員組織によるデジタル事業プラットフォームです。

---

## 🌟 主な特徴

1. **完全無料（維持費0円）で稼働**:
   - Webダッシュボード: **Streamlit Community Cloud** (無料)
   - プログラム保管: **GitHub** (無料)
   - AI思考エンジン: **Google Gemini API** (開発者向け無料枠)
2. **専門AI社員チームによる自動出版（第1号子会社: NotePub AI）**:
   - 👩‍💼 **一条 蓮（CEO）**: 全体統括・企画承認
   - 🔍 **風間 涼（リサーチャー）**: 市場ニーズ・読者ペルソナ分析
   - ✍️ **結城 紬（編集長）**: 無料・有料エリアの構成と本格執筆
   - 📢 **佐々木 翼（マーケター）**: X（Twitter）用告知文・集客導線作成
   - 📊 **白石 葵（アナリスト）**: 最適価格設定・売上シミュレーション
3. **将来のホールディングス化に対応**:
   - ダッシュボードからワンクリックで新しい子会社（Kindle出版、プロンプト販売、SNS代行など）を設立可能。
4. **Macの電源を切ってもOK**:
   - クラウド上で動くため、PCを閉じてもスマホからURLを開くだけでAI社員に指示を出せます。

---

## 🚀 クイックスタート（ローカルで動かす場合）

```bash
# 必要なライブラリのインストール
pip install -r requirements.txt

# ダッシュボードの起動
streamlit run app.py
```

ブラウザで自動的に `http://localhost:8501` が開き、オフィス画面が表示されます。
