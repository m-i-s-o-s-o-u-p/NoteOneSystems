## 🚀 クイックスタート（ローカルで動かす場合）

```bash
# 必要なライブラリのインストール
pip install -r requirements.txt

# ダッシュボードの起動
streamlit run app.py
```

ブラウザで自動的に `http://localhost:8501` が開き、オフィス画面が表示されます。
